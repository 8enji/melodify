# melodify

This is the repository for melodify's ml models, github pages, and other code.

`/models`: This contains the machine learning models we will make this semester
- `/models/kmeans_submission.ipynb`: This file contains the source code for the k-means model
- `/models/random_forest_submission.ipynb`: This file contains the source code for the random forest model
  
`/data`: This contains the data used for our ML models

`/pages`: contains all of the source code for our github pages website that explains our project

- `/css`: contains css source code for our website

- `/images`: contains the images we use in our website

- `{contributions, final, index, midterm, proposal, references}.html`: the HTML files for each respective page
